# DIY FC PARTYBUTTON
ファミコン用の周辺機器「パーティタップ」の互換品です。
Arduinoを使って作ります。「ギミアぶれいく 史上最強のクイズ王決定戦」で動作を確認しました。

## 部品
・Arduino Pro Mini互換基板。

・スイッチ1～6。

・エキスパンション端子用通信ケーブル。

・ブレッドボード。

・ジャンパーワイヤー。
